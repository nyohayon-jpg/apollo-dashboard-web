# apollo-dashboard-web

Frontend for the **Project Apollo** dashboard, used by Greenleaf Grocers store managers to see stock levels and sales trends.

## Features (planned)
- Sales charts with 7-day / 30-day toggle
- Low-stock alert cards
- Export to Excel
- Hebrew and English interface (RTL support)
